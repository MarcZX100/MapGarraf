Qué datos se tratan y para qué

  • Ubicación del bus: solo se solicita cuando una persona pulsa «Compartir este bus» y concede permiso de geolocalización. Se usa para mostrar en el mapa la señal que esa persona ha decidido compartir con otros viajeros y para estimar el avance del bus.
  • Datos opcionales del servicio: sentido del viaje, hora de salida y ocupación, si la persona los facilita. Se muestran junto a la señal para que otros viajeros puedan interpretarla.
  • Datos técnicos necesarios: el servidor puede procesar datos de conexión de la solicitud para prestar y proteger la web. No se crean cuentas ni se solicita el nombre o el identificador del dispositivo.
  • Analítica web: Google Analytics 4 (ID de medición G-QGHZ9BZ1EF) se carga únicamente si la persona acepta las cookies analíticas. Se utiliza para entender el uso general de la web. Rechazar o retirar el consentimiento no impide usar el mapa.

Ubicación compartida y conservación

La ubicación es una aportación voluntaria, no una ubicación proporcionada por BusGarraf. Mientras una señal recibe actualizaciones, el mapa muestra su posición como señal en vivo. Si deja de recibir actualizaciones, al cabo de un minuto deja de mostrar el punto exacto como posición en vivo y pasa a mostrar una estimación. La API puede seguir entregando la última coordenada exacta durante un máximo de 20 minutos desde su última actualización para que el mapa calcule esa estimación. El servidor elimina la señal de su base de datos en un máximo de 24 horas. Al pulsar «Dejar de compartir», la señal se elimina inmediatamente. No compartas tu ubicación si no quieres que otros visitantes puedan consultar estas coordenadas durante ese periodo.

Base jurídica

La publicación de la ubicación y los datos opcionales se realiza porque la persona activa voluntariamente esa función y solicita que su señal se muestre a otros visitantes. La analítica se basa en el consentimiento previo y revocable. Las operaciones técnicas imprescindibles para servir y proteger la web se realizan para mantener el servicio y prevenir abusos.

Destinatarios y servicios externos

Las coordenadas y datos opcionales de una señal compartida son accesibles a los visitantes de la web mediante el mapa y la API pública durante los plazos descritos arriba. La aplicación utiliza mapas y recursos de OpenStreetMap; el navegador puede solicitar imágenes de mapa a sus servidores. Según la configuración de la instalación, el trazado de calles puede solicitarse a un servicio de rutas OSRM. Estas solicitudes de mapas no incluyen la coordenada GPS compartida del viajero desde el código de la aplicación.

Si se acepta Analytics, Google puede recibir datos de uso y los identificadores de cookies analíticas. Google tratará esos datos conforme a sus condiciones y política de privacidad. Consulta la política de privacidad de Google. La configuración de conservación de datos de la propiedad de Analytics se debe revisar directamente en Google Analytics; esta web no puede confirmar desde el código cuál es el plazo configurado allí.

Derechos y contacto

Para ejercer los derechos de acceso, rectificación, supresión, oposición, limitación o portabilidad, o retirar el consentimiento analítico, contacta con el responsable en la dirección que se publicará en esta página. También puedes reclamar ante la Agencia Española de Protección de Datos. Para borrar una señal activa, utiliza «Dejar de compartir»; la eliminación se solicita inmediatamente.

Menores y uso responsable

La web está pensada para viajeros. No compartas información personal en los campos opcionales. Activa la ubicación solo cuando quieras compartir el trayecto y utiliza el servicio como pasajero, nunca mientras conduces.
